<section class="page-intro"><p class="eyebrow">WHY THIS EXISTS</p><h1>Small, safe progress.</h1><p>This project turns two weekly gym visits into a routine that is easy to repeat and easy to review. Each session combines moderate cardio, machine-friendly strength work, and core stability.</p></section>
<section class="about-list"><h2>How to use it</h2><ol><li>Alternate Set A and Set B on Tuesday and Saturday.</li><li>Use the first visit to calibrate loads, not to test limits.</li><li>Log the actual session, including rest, effort, and anything that felt wrong.</li><li>Review the monthly stats and adjust only one variable at a time.</li></ol><h2>Privacy</h2><p>This public repository does not store a name or geolocation. Keep entries to non-sensitive training data. Do not add diagnoses or medical history.</p><h2>Image credits</h2><p>Exercise photographs and diagrams are used under Creative Commons licenses. See the repository file <a href="https://github.com/ottoottone/prj-gym/blob/master/notes/image-credits.md">image-credits.md</a> for creators, licenses, and source links.</p></section>
